# 架构概览

本项目实现授权证据生命周期核心，采用分层架构，职责清晰。

## 分层

- **domain**：领域对象、状态机、不变量与仓库接口。
- **application**：应用服务，协调事务与领域逻辑。
- **repository**：文件系统持久化，保证原子写入。
- **journal**：写前日志，用于崩溃恢复。
- **recovery**：快照与恢复管理。
- **scheduler**：后台到期任务调度。
- **query**：派生查询与风险排序。
- **audit**：审计链。

## 关键设计

- 授权范围只允许收窄，不能由复核步骤静默扩大。
- 条件版本随决策冻结，暂停期间迟到操作不改变有效性。
- 委托链必须无环且不得扩大上游范围。
- 所有持久化写入带版本、长度与校验，支持安全尾部截断、快照轮换与崩溃恢复。
- 所有公开状态修改均为确定性事务，使用互斥锁与乐观版本号保护共享状态。

## 数据流

1. 主体与授权申请创建。
2. 提交复核，冻结条件版本。
3. 多轮复核，产生决策凭据。
4. 启用授权，执行范围与委托校验。
5. 生命周期管理：暂停、恢复、到期、撤回。
6. 查询与审计。
